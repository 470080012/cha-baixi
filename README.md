# 茶百戏 · 盏中丹青

**参赛类别：AI 交互应用组**  
**作品形式：HTML5 互动网页**  
**文化主题：宋代点茶与茶百戏数字艺术体验**

## 作品简介

《茶百戏·盏中丹青》以宋代点茶与茶百戏为文化基础，通过择盏、择茶、注汤、击拂与水丹青创作，将传统茶文化转化为可操作的数字艺术体验。作品中的注汤次数、水量、色彩与创作笔触经过交互化简化和艺术处理，不作为宋代点茶工艺的完整复原。

## 运行方式

本项目为纯静态 H5，无需安装、无需后端服务，也不依赖小红书运行环境。

推荐通过任意静态 Web 服务器打开。例如在项目目录运行：

```bash
python3 -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

也可直接部署至任意支持静态网页的 HTTPS 托管服务。

## 技术结构

```text
index.html     页面结构与入口
style.css      页面样式与响应式适配
app.js         玩法流程、交互与本地收藏
renderer.js    Canvas 茶盏、茶汤与水丹青渲染
audio.js       浏览器音效与背景声音
assets/        图片与字体资源
```

## 浏览器能力

- 手机与桌面浏览器均可体验
- 使用 Pointer Events / Canvas 完成交互
- 使用 IndexedDB / localStorage 保存“茶戏匣”收藏
- 作品图片可直接下载
- 支持 Web Share 的移动浏览器可调用系统分享
- 不支持系统分享时自动回退为图片下载

## 文化表达说明

作品以赵佶《大观茶论》、蔡襄《茶录》、陶谷《清异录》等相关记载作为文化线索。建窑黑釉盏、点茶、击拂与茶百戏等内容保留历史依据；汝窑、定窑选择，三款茶的视觉色彩，以及彩色笔触、萌宠和预设小景属于当代数字艺术演绎。

2017年，茶百戏列入福建省第五批省级非物质文化遗产代表性项目名录。
